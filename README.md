# FABRICA COFFEE ADMIN — браузерное демо

Бесплатная тестовая версия: отображение и правка примерного меню двух филиалов в браузере.

## Важно

- Без сервера, авторизации и связи с действующим сайтом Tilda.
- Изменения сохраняются только в localStorage браузера пользователя (не общая база данных).
- Используются отдельные реальные позиции и цены из публичного меню на момент подготовки; перенос не полный.
- Не использовать как рабочую систему управления заказами/товарами или замену боевого каталога.
- Для настоящей системы продолжайте разработку отдельного Node.js + SQLite приложения с защищённым API и постоянным диском.

Размещено на GitHub Pages, бесплатно, без секретов или приватных данных.
